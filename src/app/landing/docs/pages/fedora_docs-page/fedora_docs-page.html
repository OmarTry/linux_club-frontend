HISTORIA: EL ORIGEN DE FEDORA

Fedora nació de un proyecto comunitario impulsado por Warren Togami en 2002,

originalmente concebido para proveer paquetes de software adicionales para Red Hat Linux.

Con la discontinuación de Red Hat Linux (RHL) en favor de Red Hat Enterprise Linux (RHEL),

Fedora emergió como el sucesor comunitario y el laboratorio de innovación principal.

"First, Freedom, Friends, Features" - Los cuatro fundamentos de Fedora.

Hoy, Fedora sirve como el 'Upstream' para RHEL, probando tecnologías disruptivas

como Systemd, Wayland y PipeWire antes de que lleguen al sector empresarial.

INNOVACIÓN DE KERNEL

Siempre a la vanguardia. Fedora implementa las versiones más recientes del Kernel de Linux, garantizando compatibilidad con hardware de última generación y mejoras de rendimiento inmediatas.

--latest-stable
desktop_windows

PURE GNOME SHELL

Experiencia GNOME pura sin modificaciones. Fedora es el estandarte de la visión original de GNOME, ofreciendo un flujo de trabajo enfocado y minimalista para máxima productividad.

--vanilla-ui
package

FLATPAK NATIVO

Integración total con Flatpak y Flathub. El futuro de la distribución de software es el aislamiento, y Fedora lo lidera proporcionando aplicaciones actualizadas y seguras.

--sandboxed
security

SECURITY (SELinux)

Seguridad de grado industrial activada por defecto. Security-Enhanced Linux proporciona control de acceso obligatorio (MAC) para mitigar vulnerabilidades.

--enforcing

04

GUÍA DE INSTALACIÓN

# STEP 01: DOWNLOAD ISO

Visita getfedora.org y descarga el 'Workstation Live ISO'.

# STEP 02: FLASH DRIVE

Utiliza Fedora Media Writer o dd para crear el medio de instalación.

$ sudo dd if=Fedora-Workstation-Live.iso of=/dev/sdX bs=4M status=progress

# STEP 03: ANACONDA INSTALLER

Inicia desde el USB y sigue el asistente gráfico Anaconda para particionar discos.

# STEP 04: POST-INSTALL UPDATE

Reinicia y ejecuta la primera actualización del sistema.

$ sudo dnf upgrade --refresh
