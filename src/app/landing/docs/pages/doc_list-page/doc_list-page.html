Linux Club - /usr/share/doc/man_pages

Bienvenido al manual oficial del club. Este documento actúa como el punto de entrada para nuevos usuarios y entusiastas del software libre. Navegue usando el scroll o el teclado. Al final podrás ver documentación acerca de algunas distribuciones con guía práctica.

--status-stable --encoding-utf8 --access-public

# 1. GUÍA DE INICIO RÁPIDO

Para comenzar tu viaje en Linux, lo primero es familiarizarse con la línea de comandos. La terminal no es solo texto; es el control total del sistema.

// Actualizar repositorios

$ sudo apt update && sudo apt upgrade

// Listar archivos con detalle

$ ls -la

// Navegar al directorio home

$ cd ~/home

// Consultar ayuda de comandos

$ man [comando]

# 2. ARQUITECTURA DEL SISTEMA

[ KERNEL ]

El núcleo del sistema. Gestiona el hardware, la memoria y la comunicación entre procesos. Es la base de todo.

[ SHELL ]

Intérpretes de comandos:

  • > bash (estándar)
  • > zsh (personalizable)
  • > fish (amigable)

[ ENTORNO ]

Interfaces gráficas (DE/WM): GNOME para productividad, KDE Plasma para personalización, e i3wm para tiling puro.

# 4. GLOSARIO PARA RECIÉN LLEGADOS

Kernel:

El motor central del sistema operativo que gestiona los recursos de hardware.

Shell:

La interfaz de texto que recibe tus comandos y los envía al sistema.

Root:

El superusuario con control total sobre todos los archivos y procesos.

Distro:

Una distribución específica de Linux configurada con software y utilidades propias.

TTY:

Teletipo o terminal física/virtual para interactuar con la shell.

# 5. TABLA DE COMANDOS ESENCIALES

Comando Acción (ES)
ls Lista archivos en el directorio actual
cd Cambia de directorio
mkdir Crea una nueva carpeta
rm Elimina archivos o directorios
sudo Ejecuta con privilegios de superusuario
apt/pacman Gestión de paquetes de software

# 6. TIPS DE SUPERVIVENCIA

[ TIP_01 ]

No temas a la terminal. Es una herramienta, no un laberinto.

[ TIP_02 ]

Lee siempre el manual usando el comando man [comando].

[ TIP_03 ]

Usa el TAB para autocompletar rutas y comandos rápidamente.
